# README banner generation prompts

Generated with the built-in image generation tool. Each banner is an original 3:1 raster image.

Repository assets are WebP at the original 2172 × 724 resolution, encoded with `cwebp -q 85 -m 6`. Original PNGs remain outside the repository in the image generator output directory.

## Spicerack

```text
Use case: stylized-concept
Asset type: wide GitHub README banner for the open-source repository spicerack.
Generate ONE finished horizontal banner, approximately 3:1 aspect ratio, ideally 1800x600 or 1536x512.
Primary request: avant-garde cyberpunk technical concept art, Ghost in the Shell-inspired analog anime production design mixed with an exploded engineering drawing and an experimental futuristic prototype sheet. Original artwork.
Subject: an exploded modular rack of small cybernetic tool cartridges, a poetic futuristic interpretation of a spice rack for coding-agent skills, extensions and workflows. Suspended translucent housings, exposed connectors, circuit membranes and detached precision components arranged into a coherent horizontal assembly. It should feel like an engineer and an avant-garde anime art director collaborated on an unfinished machine study.
Style/medium: hand-inked technical linework, restrained cel shading, ghosted construction geometry, drafting-paper grain, selective photostat artifacts, subtle registration offsets. Sophisticated editorial composition with meaningful empty space. Dense localized detail rather than wall-to-wall noise.
Color palette: near-black ink and deep petrol-blue drafting ground, bone-white drawing lines and lettering, selective oxidized teal / cold cyan illumination with tiny vermilion registration accents.
Composition: wide landscape. Large lowercase title "spicerack" on the left integrated into the negative space, clean and readable at GitHub content width; exploded machinery extends across center and right. Keep comfortable margins and the whole artwork composed for the wide frame.
Text (verbatim): "spicerack". Only this readable word; no subtitles, no slogans, no other legible labels. Diagram marks may be abstract nonalphabetic ticks, nodes, dotted guides and dimension lines.
Mood: cerebral, mysterious, industrial, deliberate experimental technology; visual depth and angular technical beauty.
Avoid: literal spice bottles, cooking illustrations, characters or recognizable franchise imagery, generic neon city skyline, rainbow neon, glossy gamer aesthetic, excessive HUD boxes, labels saying proof of concept or prototype, watermark. Opaque background.
```

## Harvest

```text
Use case: stylized-concept
Asset type: wide GitHub README banner for the coding-agent skill harvest in the spicerack repository.
Generate ONE finished horizontal banner approximately 3:1 aspect ratio, matching the companion spicerack banner's visual family.
Primary request: avant-garde cyberpunk technical concept art, Ghost in the Shell-inspired analog anime production design mixed with an exploded engineering drawing and deliberate experimental prototype study. Original artwork.
Subject: abstract visual metaphor for harvesting useful features from diverged code branches: two elegant branching bundles of fine cybernetic circuits feed a suspended exploded selection mechanism, with discrete translucent circuit wafers separated out and a few chosen modules precisely realigned into one clean outgoing assembly. Evoke disentangling, inspection and deliberate selection. Make this a beautiful speculative machine diagram, not a literal flowchart or UI.
Style/medium: meticulous hand-inked technical illustration, restrained anime cel shading, ghosted construction geometry and dimension guides, drafting-paper grain, selective photostat artifacts, subtle registration offsets. Exposed connectors, crystalline teal membranes, layered metal contours. Localized detail and generous dark negative space.
Color palette: near-black and deep petrol-blue drafting ground, bone-white diagram lines and title lettering, oxidized teal/cold cyan translucent circuitry, tiny vermilion registration accents. Companion aesthetic: warm pale engineered housings floating on a dark technical sheet.
Composition: true wide landscape. Large clean lowercase title "harvest" in the left negative space, readable at GitHub content width; branching exploded machine study centered and extending toward the right. Distinct silhouette from a tool rack: an airy bifurcating network, separated wafers, selection and recombination rather than rows of cartridges. Comfortable margins.
Text (verbatim): "harvest". Only this readable word. No captions, subtitles, slogans or other legible labels. Diagram annotations only abstract nonalphabetic ticks, nodes, dotted guides and geometric marks.
Mood: cerebral, mysterious, industrial, quietly radical, engineered yet unfinished.
Avoid: crops, agricultural harvest imagery, humanoid characters, recognizable franchise imagery, generic neon city skyline, rainbow neon, glossy gamer aesthetic, HUD boxes, labels saying proof of concept or prototype, watermark. Opaque background.
```
